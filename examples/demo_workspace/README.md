# InsightFlow Agent V2 合成演示资料

## 说明

本目录包含用于 V2 最终验收和演示的合成资料。所有数据均为虚构，不包含真实个人信息或商业数据。每个文件均可正常打开和使用。

## 文件清单

| 文件 | 类型 | 用途 |
|------|------|------|
| `sales_survey_2025q2.csv` | CSV | 2025年Q2销售调查数据，包含地区、产品、销量、收入和评分 |
| `survey_incomplete.csv` | CSV | 含缺失值的调查问卷数据，用于测试数据质量检测 |
| `job_analysis_2025q2.xlsx` | XLSX | 多工作表岗位分析表（岗位对比、技能矩阵、投递记录） |
| `grading_rubric.pdf` | PDF | 课程数据分析报告评分标准（文本型PDF） |
| `analysis_standards.md` | Markdown | 数据分析项目规范文档，包含表格、代码块和清单 |
| *(图片需手动添加)* | PNG/JPG | 建议使用清晰中文截图或通知照片用于OCR测试 |

## 推荐演示任务

### 任务1：销售数据分析
选择 `sales_survey_2025q2.csv`，输入：
> 分析各地区各产品的销售表现，找出最佳销售组合。

### 任务2：数据质量检查
选择 `survey_incomplete.csv`，输入：
> 检查这份问卷数据的质量，指出缺失值和潜在问题。

### 任务3：岗位与技能对比
选择 `job_analysis_2025q2.xlsx`（多工作表），输入：
> 对比不同公司的岗位要求，与我的技能矩阵进行差距分析。

### 任务4：跨文件分析
选择 `sales_survey_2025q2.csv` 和 `grading_rubric.pdf`，输入：
> 根据评分标准，检查销售数据是否满足课程分析报告的要求。

### 任务5：规范文档检索
选择 `analysis_standards.md`，输入：
> 查询数据分析项目的质量检查清单和报告格式要求。

## 生成方式

所有CSV和XLSX文件通过 Python 标准库（csv、openpyxl）生成，PDF 通过 PyMuPDF 生成，Markdown 为纯文本文件。生成脚本位于 `scripts/generate_demo_materials.py`（待添加）。

## 注意事项

- 所有数据均为虚构，不代表任何真实公司、产品或个人；
- 图片演示文件需用户自行添加（建议使用不含个人信息的公开截图或通知）；
- 不包含扫描PDF（需要真实硬件OCR）；
- 不包含真实个人信息。
