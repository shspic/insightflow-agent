# Contributing to InsightFlow Agent

Thanks for your interest in contributing to InsightFlow Agent.

## Ways to contribute

You can help by:
- Reporting bugs
- Suggesting features
- Improving documentation
- Adding or improving tests
- Fixing issues
- Improving RAG, Agent, MCP, security, or deployment workflows

## Before opening an issue

Please search existing issues first and provide enough information to reproduce the problem.

Do not include API keys, passwords, tokens, private documents, or other sensitive data.

## Pull requests

1. Create a branch for your change.
2. Keep changes focused on one problem.
3. Add or update tests when behavior changes.
4. Run the relevant backend/frontend tests described in the README.
5. Make sure no secrets or private data are committed.
6. Explain what changed and how it was verified in the PR description.

## Development

See README.md and docs/ for local setup, architecture, testing, evaluation, and deployment instructions.

## Security

Please do not report security vulnerabilities in public issues. See SECURITY.md instead.
