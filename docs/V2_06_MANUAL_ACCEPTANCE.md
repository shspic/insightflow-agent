# V2-06 手动验收清单

## 1. 验收准备

建议使用隔离的测试数据库、普通用户和管理员测试账号，不使用真实用户资料，不调用真实 DeepSeek。准备一个 CSV、一个多 Sheet Excel、一份文本 PDF、一份扫描 PDF 和一张测试图片。启动 API、前端和单 Worker 后再进行需要执行任务的场景。

每项分别在桌面和适用的移动端尺寸检查。失败时记录：页面 URL、账号角色、工作区/任务 ID、浏览器、控制台错误、网络响应状态和截图；不要记录密码、邀请码明文或用户文件内容。

## 2. 必验页面与流程

### 1. 登录

- [ ] 账号和密码均有可见 label，Tab 顺序正确，Enter 可提交。
- [ ] 密码显示/隐藏按钮有可访问名称。
- [ ] 提交中按钮不可重复点击，失败显示统一安全文案。
- [ ] 成功后进入工作区，未保存 Token 到 localStorage。

### 2. 注册

- [ ] 账号、密码、确认密码、邀请码字段齐全。
- [ ] 密码要求和两次密码一致性实时提示。
- [ ] 错误靠近字段或在表单 Alert 中显示，成功后可登录。

### 3. 密码重置

- [ ] 申请结果不暴露账号是否存在。
- [ ] 请求中不可重复提交，成功提示可被屏幕阅读器读出。

### 4. 强制改密

- [ ] `must_change_password` 用户无法访问其他受保护路由。
- [ ] 页面说明原因，新旧密码校验正确，成功后解除强制流程。

### 5. 工作区列表

- [ ] 首次加载显示 Skeleton；无数据时显示创建入口。
- [ ] 搜索与状态筛选组合正确，移动端为单列。
- [ ] 更新时间、文件数、任务数仅展示真实接口数据。

### 6. 创建工作区

- [ ] 对话框有焦点约束、Escape 关闭和字段错误。
- [ ] 创建成功只更新必要列表并显示 Toast。
- [ ] 配额接近或达到上限时显示原因和下一步。

### 7. 文件批量上传

- [ ] 拖入支持和不支持类型时立即区分。
- [ ] 单文件过大、超过批量数量和单文件失败不阻断其他文件。
- [ ] 可单个移除、清空、重试，移动端可打开系统文件选择器。

### 8. 文件理解

- [ ] 批量理解时状态从已上传进入理解阶段并最终 ready/failed。
- [ ] Profile 结构化显示摘要、工作表/页数、质量、角色、标签、降级和版本。
- [ ] 页面不显示服务器路径或大型原始 JSON。

### 9. 文件关系

- [ ] 可生成候选并筛选 suggested、confirmed、rejected。
- [ ] 待确认、确认、拒绝、类型和备注区别清楚。
- [ ] 匹配分不被描述成准确率，移动端切换为卡片。

### 10. Workspace Context

- [ ] 直接访问 `/workspaces/:id/context` 并刷新可恢复。
- [ ] Context 只汇总真实文件/关系信息，不触发 Supervisor 执行。

### 11. 新建任务

- [ ] 分步完成选择文件、目标、偏好、追问、计划和执行。
- [ ] 未就绪文件、质量问题和待确认关系有明确提示。
- [ ] DeepSeek、OCR、复用/重分析选项与真实 API 能力一致。

### 12. 主动追问

- [ ] 每个问题显示“为什么需要”和推荐选择。
- [ ] 可提交回答或按建议继续，重复提交被阻止。

### 13. 计划修改和确认

- [ ] 步骤以 Agent、工具、输入、依赖、调用数、假设和风险展示。
- [ ] 可上下调整、删除允许的可选步骤、修改目标/文件并重新生成。
- [ ] 不出现原始 JSON、内部 Prompt 或未注册工具。
- [ ] 保存失败后用户当前编辑内容仍保留。

### 14. 排队

- [ ] 确认后进入 queued，页面说明等待 Worker。
- [ ] 刷新后仍能恢复同一服务端任务，不依赖 localStorage。

### 15. SSE 执行

- [ ] 明确显示连接中、SSE 已连接、重连中或轮询模式。
- [ ] 步骤、事件、进度和耗时实时更新，事件不重复。
- [ ] 终态停止 SSE/轮询，离开页面后没有重复连接。

### 16. 取消

- [ ] 取消前出现确认，说明不可中断库调用采用协作式取消。
- [ ] 浏览器关闭不会取消任务，取消后最终状态与服务端一致。

### 17. 失败重试

- [ ] 错误展示可理解原因和下一步，技术标识默认折叠。
- [ ] 可重试步骤显示重试次数，不重复执行不应重跑的已完成步骤。

### 18. 报告阅读

- [ ] 桌面目录/正文/资产层级清楚，正文行宽和行高舒适。
- [ ] 标题目录可定位，表格只在局部横向滚动。
- [ ] 图表可放大并有文本摘要，代码/JSON 默认折叠。

### 19. 版本切换

- [ ] 版本排序正确，可切换当前版本并标识当前项。
- [ ] 删除历史版本有确认，不误删当前版本。

### 20. Markdown/DOCX/PDF 导出

- [ ] 三种导出均显示进行中、完成或失败。
- [ ] 下载经过鉴权接口，文件名和类型正确，失败不会留下无效链接。

### 21. 反馈和重新生成

- [ ] 必须先选择问题类型，说明有字数限制。
- [ ] 重新生成前展示复用/重分析、模板和配额影响。
- [ ] 明确旧版本保留，重复提交被阻止，成功后有状态。

### 22. 使用量

- [ ] 显示当前值、上限、重置时间和管理员覆盖。
- [ ] 80% 以上预警，超限给出可执行建议。
- [ ] 管理员无限配额仍显示系统安全上限。

### 23. 邀请码

- [ ] 创建/轮换前确认，一次性明文只在专门对话框展示。
- [ ] 对话框提示立即复制，关闭后不能从前端再次查看明文。

### 24. 密码重置管理

- [ ] 临时密码同样只显示一次，关闭后前端状态清空。
- [ ] 高风险操作有确认，普通用户看不到入口。

### 25. Worker 监控

- [ ] healthy、degraded、unready 区分明确。
- [ ] 心跳超时、Worker 失联和 queued 积压有醒目提示。

### 26. 评估页面

- [ ] deterministic 结果标注为“规则自检”，不称为模型准确率。
- [ ] 管理页不泄露普通用户原始文件或报告正文。

### 27. 清理 dry-run

- [ ] 默认只能执行 dry-run 预览。
- [ ] 页面清楚区分预览与实际删除，不提供未经确认的批量危险操作。

### 28. 360px 移动端

- [ ] 无页面级横向滚动；导航为抽屉；对话框为底部 Sheet/全屏。
- [ ] 操作按钮不超出视口，触摸目标合理，长文件名可查看。
- [ ] 任务步骤、事件和报告目录仍可读。

### 29. 深色主题

- [ ] 浅色、深色和跟随系统三种模式可切换。
- [ ] 刷新后仅保留主题偏好，不保存敏感业务数据。
- [ ] 文字、边框、焦点和各状态颜色对比可辨。

### 30. 键盘操作

- [ ] 使用 Tab/Shift+Tab 可到达所有主要操作，无键盘陷阱。
- [ ] `focus-visible` 清晰，skip link 可跳到主内容。
- [ ] Dialog 初始焦点、Tab 约束、Escape 和焦点恢复正确。
- [ ] 图标按钮均有可访问名称，状态更新和 Toast 通过 aria-live 宣告。

## 3. 已自动或真实浏览器抽查的范围

- 纯逻辑自动测试：状态文案、错误映射、配额预警、计划校验、SSE 合并去重、报告版本、文件类型、权限导航、一次性秘密和主题读取。
- 真实浏览器抽查：登录页桌面、360px、768px 深色主题及键盘焦点。
- 尚需人工完成：需要测试账号、真实工作区数据、Worker、导出文件和管理员权限的 2 至 27 项完整业务验收。

构建成功只能证明代码可生产编译，不能代替上述业务、响应式和可访问性验收。
