# InsightFlow Agent 3～5 分钟演示脚本

这个脚本适合录屏、面试现场讲解或 GitHub 项目展示。演示时按“项目定位 → 本地启动 → 文件处理 → Agent 执行 → 执行轨迹 → 报告生成”的顺序推进。

## 0. 演示前准备

操作：

- 准备一个小型 CSV 或 Excel 测试文件。
- 准备一个可提取文本的 PDF 测试文件。
- 准备一张包含清晰文字的图片。
- 确认 `backend/.env` 已从 `backend/.env.example` 复制得到。
- 如果要演示 OCR 成功结果，确认本机已配置 Tesseract；如果没有配置，可以演示系统返回的明确提示。

强调：

- 演示文件不要包含真实隐私数据。
- 这个项目当前是本地演示版，不演示虚假的公网部署地址。

## 1. 打开 GitHub README，介绍项目定位

操作：

- 打开 GitHub 仓库 README 或本地 README 预览。
- 指向项目标题、核心功能、系统架构图和 Agent 工作流说明。

强调：

- InsightFlow Agent 是多模态文档与数据分析智能体。
- 它不是普通聊天机器人，而是围绕文件执行任务的 Agent 应用。
- 项目覆盖上传、解析、分析、图表、PDF RAG、OCR、报告和执行轨迹。

建议话术：

> 这个项目的重点不是做一个聊天窗口，而是让用户上传真实文件后，通过自然语言触发后端工具链完成分析、检索、识别和报告生成，并且能看到 Agent 每一步执行轨迹。

## 2. 使用 Docker Compose 启动项目

操作：

```powershell
docker compose up --build
```

强调：

- Docker Compose 同时启动 FastAPI 后端和 React 前端。
- 后端数据目录和文件存储目录挂载到本地。
- Docker 演示版默认不内置 Tesseract OCR，OCR 是否可用取决于容器或本机配置。

## 3. 打开前端页面

操作：

- 打开 [http://localhost:5173](http://localhost:5173/)。
- 简单展示首页、导航和后端连接状态。

强调：

- 前端使用 React + Vite。
- 后端 API 地址默认是 [http://localhost:8000](http://localhost:8000/)。
- 页面是演示工具型应用，不是营销落地页。

## 4. 上传 CSV / Excel 文件

操作：

- 进入上传页面。
- 选择 CSV 或 Excel 测试文件并上传。
- 查看文件列表中的 ID、文件名、文件类型、状态和上传时间。

强调：

- 后端限制文件类型和大小。
- 原始文件保存到 `storage/uploads`。
- 文件元数据写入 SQLite 的 `files` 表。

## 5. 解析文件

操作：

- 点击文件列表中的“解析”按钮。
- 展示字段名、行数、列数、缺失值统计和前 5 行预览。

强调：

- CSV / Excel 解析使用 Pandas 和 openpyxl。
- 解析结果保存到 `files.schema_json`。
- 当前阶段只做基础解析，不执行用户输入的任意代码。

## 6. 提交数据分析任务

操作：

- 进入工作区。
- 选择刚才上传的 CSV 或 Excel 文件。
- 输入：“帮我分析这个文件的数据概况和缺失值情况。”
- 提交任务并查看最终回答。

强调：

- 用户输入会进入任务系统。
- LangGraph 会先分类任务，再生成计划、选择工具、执行分析并整理结果。
- 数据分析调用的是预设 Pandas 工具函数。

## 7. 查看 Agent 执行轨迹

操作：

- 在任务结果下方查看执行轨迹。
- 依次展开或查看这些节点：
  - `classify_task`
  - `plan_task`
  - `route_tools`
  - `execute_tool`
  - `write_result`
  - `save_result`

强调：

- 每个节点记录输入、输出、状态、耗时和错误信息。
- 执行轨迹写入 `tool_calls` 表。
- 这让 Agent 的行为可解释、可调试、可展示。

## 8. 生成图表

操作：

- 回到文件列表，点击“生成图表”。
- 展示缺失值统计图、数值统计图或分类 Top 5 图。

强调：

- 图表由 Matplotlib 在后端生成。
- 图表文件保存到 `storage/charts`。
- 前端通过后端静态路径展示图片，不暴露本地绝对路径。

## 9. 上传 PDF，执行 PDF RAG 问答

操作：

- 上传一个可提取文本的 PDF。
- 点击“索引 PDF”，或在工作区选择 PDF 后直接提问。
- 输入：“这份文件中说明了哪些关键内容？”
- 查看回答、页码和引用片段。

强调：

- PDF 文本由 PyMuPDF 提取。
- 初版 RAG 使用轻量检索方案，优先保证功能闭环。
- 检索 chunk 保存到 `file_chunks` 表。
- 回答包含引用来源，便于追溯。

## 10. 上传图片，执行 OCR

操作：

- 上传图片文件。
- 点击“执行 OCR”。
- 查看 OCR 识别文本，或查看 OCR 未配置时的明确提示。
- 也可以在工作区选择图片并输入：“识别这张图片里的文字。”

强调：

- OCR 使用 pytesseract + Pillow。
- 是否识别成功取决于 Tesseract OCR 是否在运行环境中正确配置。
- 未配置 OCR 时系统不会崩溃，会返回中文提示。

## 11. 生成 Markdown 报告

操作：

- 在工作区输入：“根据这个任务生成分析报告。”
- 查看生成后的 Markdown 报告。

强调：

- 报告会整合任务说明、文件概况、数据分析、图表、PDF 引用、OCR 结果和结论。
- 报告路径保存到 `tasks.report_path`。
- 当前版本输出 Markdown，后续可扩展 DOCX / PDF 导出。

## 12. 展示报告下载

操作：

- 点击“下载报告”。
- 展示下载得到的 `.md` 文件。

强调：

- 报告是实际落地文件，不只是页面文本。
- 下载接口不会暴露本机绝对路径。

## 13. 总结技术亮点

建议话术：

> 这个项目展示的是一个完整 AI Agent 应用闭环：React 前端、FastAPI 后端、SQLite 数据存储、文件解析、Pandas 数据分析、Matplotlib 图表、PDF RAG、图片 OCR、LangGraph 工作流、工具调用记录和 Markdown 报告生成。它当前是本地单用户演示版，重点展示 Agent 工程结构和可观测执行过程，后续可以继续增强向量检索、多文件分析、用户系统和云端部署。
