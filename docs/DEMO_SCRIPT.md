# InsightFlow Agent 项目演示脚本

这个脚本适合 3 到 5 分钟录屏或面试现场演示，重点展示“上传文件 → Agent 执行任务 → 查看轨迹 → 生成报告”的完整闭环。

## 1. 启动项目

演示命令：

```powershell
docker compose up --build
```

打开：

- 前端：[http://localhost:5173](http://localhost:5173/)
- 后端 Swagger：[http://localhost:8000/docs](http://localhost:8000/docs)

讲解重点：

- 项目使用 Docker Compose 同时启动前端和后端。
- 后端是 FastAPI，前端是 React + Vite。
- 数据存储使用 SQLite 和本地文件目录，适合本地演示和简历项目展示。

## 2. 上传文件

操作：

1. 进入上传页面。
2. 上传一个 CSV 或 Excel 文件。
3. 在文件列表中确认文件 ID、文件名、类型、状态和上传时间。

讲解重点：

- 后端会校验文件类型和大小。
- 原始文件保存到 `storage/uploads`。
- 文件元数据写入 `files` 表。

## 3. 解析与分析表格

操作：

1. 点击“解析”。
2. 查看字段名、行数、列数、缺失值和前 5 行预览。
3. 点击“分析”。
4. 查看字段类型、数值列统计、文本列高频值和缺失值统计。

讲解重点：

- CSV / Excel 解析和分析由 Pandas 完成。
- 解析结果和分析结果保存到 `files.schema_json`。
- 数据分析不是执行用户代码，而是调用预设安全函数。

## 4. 生成图表

操作：

1. 点击“生成图表”。
2. 查看缺失值统计图、数值统计图和分类 Top 5 图。

讲解重点：

- 图表由 Matplotlib 生成。
- 图片保存到 `storage/charts`。
- 前端通过后端静态路径展示图表，不暴露本机绝对路径。

## 5. PDF RAG 检索问答

操作：

1. 上传 PDF 文件。
2. 点击“索引 PDF”，或在工作区选择 PDF 后直接提问。
3. 输入类似问题：“这份文件中说明了哪些关键内容？”
4. 查看回答中的页码和引用片段。

讲解重点：

- PDF 使用 PyMuPDF 提取文本。
- 初版 RAG 使用轻量检索方案，不依赖重型向量库。
- 检索片段保存到 `file_chunks` 表。
- 回答包含来源页码和引用片段，便于追溯。

## 6. 图片 OCR

操作：

1. 上传图片文件。
2. 点击“执行 OCR”。
3. 查看识别文本。
4. 在工作区选择图片，输入“识别这张图中的文字”。

讲解重点：

- OCR 使用 pytesseract + Pillow。
- 本机需要配置 Tesseract OCR。
- Docker 演示版默认不内置 Tesseract，未配置时会返回明确提示，但不影响其他功能。

## 7. 创建 Agent 任务

操作：

1. 进入工作区。
2. 选择一个已上传文件。
3. 输入自然语言任务，例如：
   - “帮我分析这个文件的数据概况和缺失值情况。”
   - “帮我生成图表。”
   - “这份 PDF 文件中有哪些关键说明？”
   - “识别这张图片里的文字。”
4. 提交任务。

讲解重点：

- 用户输入先进入任务系统。
- 后端通过 LangGraph 工作流执行任务。
- 当前版本使用规则分类和预设工具，不接入大模型，不执行任意代码。

## 8. 查看执行轨迹

操作：

查看任务执行轨迹，重点展示以下节点：

- `classify_task`
- `plan_task`
- `route_tools`
- `execute_tool`
- `write_result`
- `save_result`

讲解重点：

- 每个节点都会记录输入、输出、状态、耗时和错误信息。
- 执行轨迹保存到 `tool_calls` 表。
- 这让 Agent 不再是黑盒，方便调试和面试讲解。

## 9. 生成 Markdown 报告

操作：

1. 在工作区输入“根据这个任务生成分析报告”。
2. 查看生成后的 Markdown 报告内容。
3. 点击下载报告。

讲解重点：

- 报告会整合任务说明、文件概况、数据分析、图表、PDF 引用和 OCR 结果。
- 报告路径保存到 `tasks.report_path`。
- 当前版本输出 Markdown，后续可以扩展 DOCX / PDF 导出。

## 10. 收尾说明

总结话术：

InsightFlow Agent 展示的是一个完整的 AI Agent 应用闭环：前端交互、后端 API、数据库记录、文件处理、工具调用、LangGraph 工作流、执行轨迹和报告输出。它不是只做聊天，而是围绕真实文件完成可追踪的任务执行。
