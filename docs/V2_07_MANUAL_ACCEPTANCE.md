# V2-07 真实上线手动验收清单

本清单只能在用户完成服务器购买、备案、DNS 和 HTTPS 后人工执行。本阶段没有声称任何公网、DeepSeek 或中国内地网络测试已经通过。

记录每项的时间、测试账号、浏览器/设备、网络、结果、证据和问题编号。

## A. 访问、安全与身份

- [ ] 1. 中国内地不使用 VPN 可打开站点，记录地域和运营商。
- [ ] 2. HTTP 自动跳转 HTTPS，证书链/域名正确，混合内容为零。
- [ ] 3. 登录与退出正常，Cookie 为 HttpOnly/Secure/SameSite 预期值。
- [ ] 4. 邀请码注册正常，失效/耗尽邀请码被拒绝。
- [ ] 5. 临时密码首次登录强制改密且不能绕过。
- [ ] 6. 两个普通用户的工作区、文件、任务、事件、报告和下载完全隔离。

## B. 文件与理解

- [ ] 7. 合法文件上传成功，超大小/数量/配额被明确拒绝。
- [ ] 8. CSV 与多 Sheet XLSX 解析、Profile 和统计正确。
- [ ] 9. 文本 PDF 分页解析、引用页码和检索正确。
- [ ] 10. PNG/JPEG/WEBP 图片 OCR 可用并标注需要人工复核。
- [ ] 11. Markdown 标题、分块和安全渲染正确。
- [ ] 12. 扫描 PDF 低文本页触发 OCR，超页数/超时受限且降级明确。
- [ ] 13. 五类文件理解状态、摘要、结构、质量和标签正确。
- [ ] 14. 文件关系有证据/匹配分，确认/拒绝/修正后行为正确。

## C. 任务与 Worker

- [ ] 15. 创建任务草稿只规划，不提前执行正式工具。
- [ ] 16. 信息不足时主动追问，达到轮次上限后假设透明。
- [ ] 17. 计划可修改/确认，未知工具和非法依赖被拒绝。
- [ ] 18. 单 Worker 认领并持久化步骤，未运行第二个 Worker。
- [ ] 19. SSE 逐条到达、无批量缓冲；断网后恢复或降级轮询。
- [ ] 20. 排队任务立即取消，运行任务在安全边界协作取消。
- [ ] 21. 失败步骤局部重试，上游成功资产不重复生成。
- [ ] 22. 使用真实生产配置调用 DeepSeek，模型名、配额和错误可观察。
- [ ] 23. Key/模型故意无效时 readiness degraded，前端显示不可用并走确定性降级。

## D. 报告与治理

- [ ] 24. Markdown、DOCX、PDF 鉴权下载，中文字体、图表和分页可读。
- [ ] 25. 报告历史版本、切换当前和旧版本保留正确。
- [ ] 26. 点赞/点踩/纠错和复用分析重新生成正确。
- [ ] 27. 上传、任务、模型、导出和存储配额正确，429 信息可理解。
- [ ] 28. 管理员监控显示任务、Worker、模型、反馈和清理元数据，不泄露正文/密钥。

## E. 运维与灾难恢复

- [ ] 29. 每日备份生成数据库、storage、manifest 和 SHA-256，未包含密钥。
- [ ] 30. 在隔离目录完成恢复演练，校验登录、文件和报告，不覆盖生产库。
- [ ] 31. 清理 dry-run 输出数量/空间；未删除活跃文件和当前报告。
- [ ] 32. `/api/health` 与 `/api/health/ready` 语义正确，健康脚本退出码正确。
- [ ] 33. 分别重启 web/backend/worker，服务和任务状态恢复符合预期。
- [ ] 34. 重启服务器后容器自动恢复，Worker 租约/心跳和 HTTPS 正常。

## F. 终端与网络

- [ ] 35. 360px 手机、平板和桌面关键流程无页面级横向滚动，键盘焦点可见。
- [ ] 36. 至少用两个中国内地运营商/网络（例如宽带与移动网络）实际访问并记录延迟、上传、SSE 和下载。

## G. 上线签字前附加检查

- [ ] `ENABLE_LEGACY_V1_API=false`、`DEBUG=false`、Secure Cookie 和精确 CORS。
- [ ] API/Worker/SQLite 未暴露公网，只有 22（受限）、80、443。
- [ ] Alembic 当前 revision 等于唯一 head。
- [ ] DeepSeek 数据发送范围、隐私说明和费用配额已由负责人确认。
- [ ] 异地备份已建立，恢复负责人和维护窗口已明确。
- [ ] 备案号和按要求的公安联网备案信息已真实展示。
